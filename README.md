- 6709650136 นายกันตณัฐ สุพัฒนานนท์
  **หน้าที่: Sensor Developer** รับผิดชอบการพัฒนาระบบอ่านค่าจากเซนเซอร์ของมือถือ เพื่อนับจำนวนก้าวเดินและจำนวนครั้งที่เขย่า โดยมีหน้าที่ดังนี้

  **Step Counter (ข้อ 1):** นับจำนวนก้าวด้วยเซนเซอร์นับก้าว (Step Counter) ที่ติดมากับมือถือ เนื่องจากเซนเซอร์นับก้าวสะสมตั้งแต่เปิดเครื่อง แอปจึงจำค่าเริ่มต้นตอนเปิดแอปไว้ และแสดงเฉพาะจำนวนก้าวที่เดินหลังเปิดแอป

  **Shake Detection (ข้อ 2):** ตรวจจับการเขย่าด้วยเซนเซอร์วัดความเร่ง (Accelerometer) นับ 1 ครั้งเมื่อเขย่าแรงเกินค่าที่กำหนด ไม่นับเมื่อขยับเบา ๆ หรือวางนิ่ง และกันการนับซ้ำโดยกำหนดให้แต่ละครั้งห่างกันอย่างน้อย 0.5 วินาที

  **Sensor Integration:** ส่งค่าจำนวนก้าวและจำนวนครั้งที่เขย่าไปแสดงบนหน้าหลัก และเตรียมข้อมูลให้ Session Logic และฐานข้อมูลนำไปใช้ต่อ

  **Sensor Testing:** ทดสอบบนมือถือจริง (Samsung Galaxy A33 5G) เนื่องจาก Emulator ไม่มีเซนเซอร์นับก้าวจริง
    - เดิน 20 ก้าว → นับได้ 19 ก้าว
    - เขย่า 5 ครั้ง → นับได้ 5 ครั้ง

  **หมายเหตุ:** เซนเซอร์นับก้าวจะอัปเดตช้ากว่าการเดินจริงไม่กี่วินาที และต้องเดินประมาณ 5–10 ก้าวก่อนจึงเริ่มนับ ซึ่งเป็นพฤติกรรมปกติของเซนเซอร์

  **ไฟล์ที่รับผิดชอบ:**

    - MainActivity.java (ส่วน Sensor)
    - AndroidManifest.xml (สิทธิ์ ACTIVITY_RECOGNITION)
